# AI/LLM & SEO: /llms.txt, /<page>/llms.txt, /robots.txt, /sitemap.xml, the
# universal prerender and the network directory. Every floor below is
# load-bearing, and run.py refuses to boot under the current one:
#   2.3.4  resolve_site_title (the /llms.txt H1 + viewer brand chip) and
#          the fixed crawler taxonomy.
#   2.5.1  the Tier-B SEO standard: configure_seo (icons, social card,
#          publisher/sameAs), crawler <title> carrying the site name,
#          per-page title/image_url/schema_type reaching the crawler
#          document, /favicon.ico answered with a redirect instead of the
#          app shell, and a prerender that no longer clobbers the
#          browser's per-page <title>. Also the tiered corpus docs
#          (/llms-small.txt, /llms-full.txt; 2.4.0+) that run.py registers
#          with lib/page_tiers.
#   2.6.0  configure_access — the enforcement half the interactive gate
#          reads, so the prerender obeys a page's tier instead of
#          publishing gated prose to crawlers.
#   2.6.1  THE PRERENDER GUARANTEE. Up to 2.6.0 the prerender div shipped
#          with a literal `hidden` attribute, so every visibility-respecting
#          text extractor read the site as "Loading..." and nothing else —
#          present and invisible, the worst of both. 2.6.1 serves it
#          visible and hides it with a synchronous inline script only JS
#          browsers run. tests/test_prerender.py pins the served shape.
#   2.7.0  Deduplication and hardening of that same block: the prerender
#          H1 no longer doubles the doc body's own markdown H1 (every page
#          was a duplicate-H1 page in a crawler's eyes), the home footer
#          stops printing its /llms.txt link twice, and the idempotency
#          probe is hardened so a page that merely MENTIONS the marker
#          keeps its prerender. THIS HOST PAID FOR THAT LAST ONE: the
#          marker sat in an index.html comment here and silently disabled
#          the universal prerender site-wide until 2026-08-22. The
#          hardening is a second line of defence, not a licence — the
#          template rule (never spell the marker in served text) and
#          tests/test_prerender.py both still stand.
#   2.7.1  THE ROUND-3 NETWORK FLOOR. llms.txt v2 discovery relations
#          (rel=alternate/describedby on both the browser and machine
#          lanes, plus matching Link headers), the Accept: text/plain
#          content ramp, and the representation content digest — the
#          surfaces the network's agent lane composes over.
#
