# Claude Code Project Guide - dash-flows

## Project Overview

**dash-flows** is a Dash component library that wraps @xyflow/react (React Flow v12) for Plotly Dash. It provides glass morphism themed flow diagram components with ELK layout support, DashIconify icon integration, and full Dash callback interoperability.

- **Version**: 1.3.0
- **Repository**: https://github.com/pip-install-python/dash-flows
- **Author**: Pip Install Python
- **Python targets only**: R and Julia bindings were removed in 1.3.0 (`build:backends` no longer passes `--r-prefix`/`--jl-prefix`).

## Technology Stack

### JavaScript (Source of Truth)
- **@xyflow/react 12.11.1** - React Flow library (updated from 12.10.1)
- **React 18** - UI framework

- **prop-types** - PropTypes for Dash component generation
- **Webpack 5** - Bundler

### Python (Auto-Generated + Examples)
- **Dash 4.2+** - Target framework (still React 18; min `dash>=4.0.0`)
- **dash-mantine-components 2.8+** - Used in examples and the docs site
- **dash-iconify** - Icon support in nodes

### Documentation site (repo root)
- Markdown-driven Dash app: `run.py` + `pages/markdown.py` auto-discovers `docs/<topic>/<topic>.md`
- Directives via `markdown2dash`: `.. exec::` (live demo), `.. source::` (code), `.. kwargs::` (prop table), `.. toc::`
- Run with `pip install -r requirements-docs.txt && python run.py` (http://localhost:8560)

```
src/lib/components/*.js  -->  webpack (build:js)  -->  dash_flows/dash_flows.min.js

```

# Run the documentation site (live demos for every example)

## CRITICAL RULES

1. **NEVER edit files in `dash_flows/*.py` directly** - They are auto-generated by `dash-generate-components`. The source of truth is `src/lib/components/`.

2. **Always run `npm run build` after changing any JS file** - This rebuilds the bundle AND regenerates Python wrappers.

3. **PropTypes are the API contract** - The `PropTypes` declarations in React components define the Python API. `dash-generate-components` reads them to create Python classes. Every prop must have a JSDoc description.

4. **React externalizes React/ReactDOM** - `webpack.config.js` marks `react`, `react-dom`, and `prop-types` as externals. They come from Dash's bundled copies.

5. **Dash component rendering** - When rendering Dash child components inside nodes, use the `renderDashComponent()` helper that handles both Dash 2.x and 3.x formats. See `src/lib/components/nodes/InputNode.js` for the canonical pattern.

6. **CSS variables use `--df-` prefix** - All custom properties start with `--df-` and map to React Flow's `--xy-` variables in `src/lib/styles/glass-theme.css`.

7. **Node/edge type registration** - The `nodeTypes` and `edgeTypes` objects in `DashFlows.react.js` (~lines 53-77) map string type names to components. New nodes/edges must be registered there AND exported from `src/lib/index.js`.

## Key DashFlows Props (Python API)

### Core
- `nodes` - List of node dicts (`id`, `type`, `data`, `position`)
- `edges` - List of edge dicts (`id`, `source`, `target`, `type`)
- `style` - Container CSS (must include `height`)

### Display
- `showControls`, `showMiniMap`, `showBackground`, `showDevTools`
- `fitView`, `colorMode` (`"light"`/`"dark"`/`"system"`)
- `themePreset` (`"glass"`/`"solid"`/`"minimal"`)
- `colorScheme` (`"default"`/`"ocean"`/`"forest"`/`"sunset"`/`"midnight"`/`"rose"`)
- `backgroundVariant` (`"dots"`/`"lines"`/`"cross"`)

### Interaction Outputs (read in callbacks)
- `clickedNode`, `doubleClickedNode`, `contextMenuNode`, `hoveredNode`
- `clickedEdge`, `selectedNodes`, `selectedEdges`, `lastConnection`
- `deletedNodes`, `deletedEdges`, `droppedNode`, `paneContextMenu`

### Handle Positioning
- `smartHandles` (bool) - Auto-route edges to closest node side (renders handles on all 4 sides)
- Per-node manual control via `data.sourcePosition` / `data.targetPosition` (`"top"`, `"bottom"`, `"left"`, `"right"`)

### React Flow 12.10.1 Props
- `connectionDragThreshold` (number) - Drag distance in px before connection starts (default 0)
- `zIndexMode` (`"default"` / `"elevate"`) - Selected elements elevate above others
- `autoPanOnNodeFocus` (bool) - Viewport pans when tabbing to nodes
- Glass connection line preview - Styled blue dashed line during edge creation
- Type-colored MiniMap - Nodes colored by type (green=input, purple=output, blue=default)
- EdgeToolbar on ButtonEdge - Set `data.showToolbar=True` on button edges for toolbar on selection

### Alignment & Interaction
- `helperLines` (bool) - Alignment guides when dragging nodes
- `helperLineThreshold` (number, default 5) - Snap distance in px
- `addNodeOnEdgeDrop` (bool) - Create node by dropping edge on canvas
- `edgeDroppedNode` (output) - Drop event data
- `nodeConnections` (output) - Map of nodeId to incoming/outgoing edges

### Undo/Redo
- `enableUndoRedo` (bool) - Enable history tracking
- `undoRedoMaxHistory` (number, default 50) - Max history snapshots
- `undoRedoAction` (`{action: 'undo' | 'redo'}`) - Trigger from callbacks
- `undoRedoState` (output) - `{canUndo, canRedo, undoCount, redoCount}`

### Computing Flows
- `computeAction` (`{action: 'compute'}`) - Trigger topological sort
- `computeResult` (output) - `{traversalOrder, nodeInputs, timestamp}`

### Sub-flows (Collapsible Groups)
- `toggleCollapseNode` (string) - Group node ID to toggle
- `collapsedGroups` (output) - Currently collapsed group IDs

### ViewportPortal
- `viewportOverlays` (array) - Floating annotations at flow coordinates `{x, y, content, style}`

### Animated Layout
- `animateLayout` (bool) - Smooth transitions when applying ELK layouts
- `animateLayoutDuration` (number, default 300) - Animation duration in ms

### Accessibility
- `ariaLabelConfig` (object) - Custom ARIA labels for regions
- `nodesFocusable` / `edgesFocusable` (bool) - Tab key navigation
- `disableKeyboardA11y` (bool) - Disable keyboard shortcuts

### Action Props (trigger from callbacks)
- `layoutOptions` - JSON string for ELK layout
- `viewportAction` - Programmatic viewport control
- `exportFlowState` / `flowState` / `restoreFlowState` - Save/restore
- `downloadImage` - Image export
- `copyAction` / `pasteAction` - Copy/paste
- `deleteElementsAction` - Programmatic deletion (undo/redo compatible)
